# 🌱 New Age Life Skills – Assignments

## 📖 About
This repository contains assignments, activities, and reflections created as part of the **New Age Life Skills** course.  
Each file focuses on developing essential **21st-century life skills** that help in personal growth, academic success, and real-world problem solving.

The purpose of this repository is to encourage **self-reflection**, **positive habits**, and **practical life skills** that are useful beyond the classroom.

---

## 🧠 Skills & Themes Covered
- Self-awareness and self-reflection
- Goal setting and time management
- Critical thinking and problem solving
- Creativity and innovation
- Communication skills (oral & written)
- Collaboration and teamwork
- Emotional intelligence and stress management
- Values, ethics, and responsible behaviour

---

## 📂 Repository Structure & Usage
- Each file represents a **specific assignment, case study, or activity** from the course.
- Files may include:
  - Reflection questions
  - Written answers
  - Real-life examples
  - Personal observations
- Open individual files to review concepts and completed work.
- This repository can be used to:
  - Track learning progress
  - Revise important topics
  - Prepare for internal or external evaluations

---

## 🎯 Objective
The main objective of this repository is to **develop practical life skills**, improve decision-making, and build confidence for academic, professional, and personal life challenges.
