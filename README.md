🌱 New Age Life Skills – Assignments
📖 About
This repository contains assignments and activities for the course New Age Life Skills.
Each file focuses on a key 21st‑century skill such as self‑awareness, communication, time management, problem solving, creativity, and teamwork.[web:233][web:241]

The goal is to reflect on real-life situations, build better habits, and develop skills that are useful beyond academics.[web:233][web:239]

🧠 Skills & Themes Covered
Self‑awareness and self‑reflection
Goal setting and time management
Critical thinking and problem solving
Creativity and innovation
Communication (oral and written)
Collaboration and teamwork
Emotional intelligence and stress management
Values, ethics, and responsible behaviour[web:233][web:236][web:237]
📂 Repository Use
Each file corresponds to a specific assignment, case study, or activity from the course.
Open the files to view questions, reflections, or written submissions.
Use this repo to track progress, revise concepts, and prepare for evaluations in New Age Life Skills.[web:241][web:232]
